# Contributing

Thanks for helping improve Resume Content Builder. Small fixes and clear ideas are welcome.

## Ways to Help

- Report a bug.
- Suggest a new source or type of career content.
- Improve the docs, prompts, or finder tools.
- Add a focused test or fix.

Please search the open issues before you create a new one. You do not need to open an issue
first for a small fix.

## Make a Change

1. Fork the repo and create a short branch.
2. Keep the change focused on one goal.
3. Follow the style and file layout used by the plugin you change.
4. Run the tests that cover your change.
5. Open a pull request and explain what changed.

For changes to Artifact Finder, you can run:

```text
python -m pytest plugins/artifact-finder/tests
```

Do not add passwords, keys, private personal data, or generated files from `artifact-results`.
Only use public career data that a person has agreed to collect.
