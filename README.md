## resumecontentbuilder
You are building a resume of you own. You already know the primary content - your projects, skills, history.

Now let's say you want to provide additional content that demonstrates your skill as a patent holder, prolific writer, spokesperson, contributor - and you wanted a way to get all them collected in one place to provide additional weight to your resume, this site provides you with that.

Currently this is provided as-is, and if you want to me to invest into this - add them as issues.
