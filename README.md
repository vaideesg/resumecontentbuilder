# Resume Content Builder

Job sites can help people find open roles. But finding a role is only the first step. People
also need a strong profile that shows why they are a good fit.

Proof of good work is often spread across the web. It may sit on LinkedIn, news pages, work
sites, or group pages. It takes time to keep each profile fresh. It can also be hard to know
what to save and what to leave out.

Resume Content Builder finds this work and puts it in one place. It can find patents, posts,
papers, talks, awards, and open source work. Each result links to proof. This helps tell a
clear and trusted story about a person's skills and impact.

People can use this content in resumes, job forms, LinkedIn profiles, and talks with hiring
teams. They do not have to write their full story again for each job. They can keep posting
updates as they work. The tool can use those public posts to help keep their profile fresh.

## Benefits for Job Search Platforms

- **More confidence for job seekers.** A rich profile helps people show their best work. It
  also gives them strong content to use when they apply for a role.
- **More trust for hiring teams.** Each item can link to public proof. This gives employers
  more facts to review and helps them trust what they see.
- **One place for career content.** A job platform can bring work from many public sources
  into one clear view. People do not have to add the same facts to many sites by hand.
- **Better job matches.** Rich career data can help search tools see a person's skills and
  impact. This can lead to roles that are a better fit for both sides.

This project is provided as-is. Please open an issue to report a problem or ask for a change.

## Artifact Finder Plugin

`plugins/artifact-finder` has tools that find patents, papers, posts, talks, certificates,
standards work, open source work, and group work. It checks who made each item. It then
creates CSV files with proof that people can use in a resume.
