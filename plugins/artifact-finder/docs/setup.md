# Setup

1. Install Python 3.10 or later.
2. Update `candidate.config.json` with public professional evidence.
3. Do not add credentials or private contact data to the configuration.
4. Confirm consent on every run.
5. Invoke a focused skill or the master `/artifact-finder` skill.

The runtime uses only the Python standard library. External source credentials, when required,
must be supplied to the relevant discovery tool and never written to the candidate config.
